## godotarpg — Demo

Demo jugable de un juego de acción isométrico en pixel art, hecho en Godot 4.
Enfrentas un boss con varias fases, habilidades a melee y a distancia.

Jugar la demo (sin instalar nada)

En la sección Releases de este repositorio.  

Descargá el `.zip` de la última versión.  

Descomprime y ejecuta `demoarpg.exe`.  

No hace falta instalar Godot ni ninguna otra dependencia.

Controles  

Acción	Tecla / Mouse    

Moverse / seleccionar objetivo	Click izquierdo  

Ataque melee	Automático al acercarte a un enemigo

Fireball (a distancia)	Q (apunta hacia donde esté el mouse)

Esquivar (roll)	(Espacio)

Qué incluye esta demo

Player tipo caballero con ataque melee, roll con invencibilidad y una skill de fireball a distancia apuntada con el mouse.

Un boss con 4 fases (basadas en % de vida), múltiples patrones de ataque (slam, charge, telegraphs múltiples, cono, invocación de minions, slash) y un modo berserk con ciclón al 50% de vida.

Barra de vida del boss en pantalla, con cambio de color e indicador de fase.


## Tech stack  
Motor: Godot 4.x
Lenguaje: GDScript
Arte: pixel art / renders isométricos
Correr el proyecto desde el editor (para desarrolladores)
Instalá Godot 4.x.
Cloná este repositorio.(recuerda cambiar los paths a los de su pc)
Abrí el proyecto desde el Project Manager de Godot (`project.godot`).
F5 para correrlo.
