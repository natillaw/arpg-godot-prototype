# ARPG Godot Prototype

Diablo-like ARPG prototype made in Godot.

## How to open
1. descargar repositorio
2. abrir Godot
3. Importar carpeta del proyecto
4. ejecutar

## Structure
- scenes/player → Player scene 
- scenes/enemies → Enemies 
- scenes/levels → Levels 
- scripts/core → Core systems 

NO TOCAR SCENES QUE NO TIENEN TU NOMBRE!
